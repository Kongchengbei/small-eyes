## 修改与模型兼容

- NPU 模型头校验分拍，保留 H×W 低 16 位再乘通道数的原有语义；首次模型加载增加四拍，缓存命中路径不变。
- 旧模型 scratch 计算拆成部分积、重组和对齐，保留全部 32 位回绕和 zero sentinel 行为；需要计算的 GAP 扫描增加三拍。
- 层权重字节数与空间范围检查分拍，每层增加两拍。模型格式、权重/偏置、算子、INT8 量化与真实循环终止条件不变。
- CONV/POOL 末元素周期继续做内部 BRAM 预取，未消费的读数由后续 flush/prime 隔开；不增加 MAC/POOL 主循环周期或外部 AXI 访问。
- 模型 RAM 的权重地址采用逐输出通道递增的运行基址，最终16位地址与原乘法取模结果相同；CONV/POOL 张量地址不再等待坐标边界选择器，原有效位继续屏蔽 padding 的内部无效预取。
- 公共层尺寸、容量和描述符校验寄存在现有元数据阶段，报错优先级不变。非法归还统计采用 pending 事件和基础计数，组合投影保持原可见计数逐拍一致。
- INT8 容量按实际预留/归还维护，防止重复归还重复增加容量；每帧最多八个 ROI、每路 56 个 INT8 位置及位置代次协议不变。

现有模型文件和固件包未修改；可继续用于上板验证。上述兼容性依据代码审查，尚无本轮板上结果或新 CoreMark/识别率/吞吐实测。历史 BRAM 2.67104 CoreMark/MHz 仍只是历史成绩。

## PHY 时钟关系与检查范围

NPU/缓冲的长路径通过 RTL 拆分改善。PHY recovery 按 IP 参考文件的时钟关系分类：采用 DDR IP pnr/ddr_test.fdc:35–37 的三条独立单组声明，对应 ddr_rst_clk、phy_dq_clk_0、phy_dq_clk_1。PDS 手册 6.2.5 中，单组与组外时钟异步，不能误读成两个组外时钟也彼此异步。

已核对 core→phy_dq_sysclk_0/1：双角 setup/hold 仍覆盖 **196/420** 个端点，两个 capture group 各 64 条 slow setup 报告路径均明确为 **MultiCycle Path Setup -end 2**。没有用分组隐藏这些数据路径；没有剩余负 async 路径。同步更新 scripts/soc_config.c，防止 menuconfig 丢失已采纳声明；Full DDR 和隔离 BRAM 的 host 配置检查通过。

时钟周期、原两拍约束、IO 设置和本工程原有 uncertainty 策略均未改变；未恢复 IP 示例额外的 0.4 ns uncertainty。这是当前工程约束下的闭合，不代表把复位线物理传播延迟缩短，也不替代实板 DDR 初始化/训练和数据正确性验收。独立 Timing Analyzer 的自动导入未形成报告，结论只依据正式 PDS 结果。
